# Модель героини для прототипа

## Файлы

| Файл | Что это |
| --- | --- |
| `female_A_rigged_safe.glb` | рабочая версия для Godot: без blend shapes и без анимаций |
| `sanitize_glb.py` | скрипт, который сделал её из исходной модели |

Исходник лежит в `models/heroine/female_A_rigged.glb` (SHA-256 `e5f8d6cd…`) и
не изменялся.

## Почему понадобилась «безопасная» версия

Исходная модель **корректна** — валидатор Khronos выдаёт 0 ошибок, все индексы,
веса и нормали в порядке. Но редактор Godot падал при её импорте. Известные
сбои импортёра Godot 4 связаны с двумя вещами, которые в модели есть:

1. **Blend shapes (морф-таргеты)** на скин-мешах. Есть открытый баг: редактор
   падает при обработке меша с морфами (godotengine/godot#78897 — падение при
   развёртке UV для лайтмап именно у мешей с blend shapes).
2. **Анимации, двигающие веса морфов** (`path: "weights"`). Все три клипа в
   модели — такие.

Заодно совпадает с известной картиной: в модели 7 морф-таргетов
(`Fists`, `FistQuarterCorrection`, `FistHalfCorrection`,
`FistThreeQuarterCorrection` на теле; 2 на линии века; 1 на веке).

Для прототипа ни морфы, ни эти анимации не нужны: поза считается кодом
(`scripts/character_anim.gd`), а «сжатый кулак» — одна готовая поза, не риг
пальцев (пальцев в скелете нет вообще).

Проверено разбором файла:

| Треугольников | 33 300 |
| Рост | 1,675 м |
| Костей | 21 |
| Сумма весов на вершину | 1.0000 (везде) |
| Морфов | 0 |
| Анимаций | 0 |

Валидатор: 0 ошибок. Предупреждения `ACCESSOR_JOINTS_USED_ZERO_WEIGHT` (61 910)
и `NODE_SKINNED_MESH_NON_ROOT` (4) остались — они безвредны и были в исходной
модели.

## Как пересобрать

```
python sanitize_glb.py ../../../models/heroine/female_A_rigged.glb female_A_rigged_safe.glb
```

Скрипт не трогает геометрию, скелет и веса — только вырезает `animations`,
`targets` у примитивов и `weights` у мешей.

## Если понадобятся морфы

Тогда источник проблемы придётся решать иначе: импортировать модель один раз
с отключённым `meshes/light_baking` в настройках импорта (`.import`), либо
пересобрать модель без морфов в Blender. Проверить это в песочнице нельзя —
Godot здесь не запускается.
