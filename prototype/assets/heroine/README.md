# Модель героини для Godot

## Актуальная связка

| Файл | Назначение |
| --- | --- |
| `female_A_rigged_safe.glb` | рабочий меш с 21-костным скелетом, без морфов и встроенных клипов |
| `female_A_rigged_safe.glb.import` | настройки импорта Godot, текстуры остаются встроенными |
| `animations/motion_set.tres` | **11 новых скелетных клипов**, отдельно от GLB |
| `animations/motion_set.json` | зеркало ключей для диагностики |
| `sanitize_glb.py` | существующая стадия подготовки безопасного GLB |
| `tools/pose_viewer.py` | прежний офлайн-просмотрщик отдельных поз |

**Для запуска достаточно Godot.** [Новая инструкция по анимациям](../../ANIMATIONS.md)
описывает витрину, генератор и тесты. Старые тестовые позы в `pose_viewer.py`
не являются источником новых движений.

## Модель и ограничения

Используется существующая производная `models/heroine/female_A_rigged.glb`.
В текущей анимационной итерации **ни этот исходник, ни safe GLB не менялись**.
Скелет — 21 кость, рост основы — 1.675 м. В теле 18 176 вершин и 33 300
треугольников; глаза и прочие части добавляются отдельными примитивами.

Костей пальцев нет. Кулаки в безопасной версии постоянно сжаты: существующий
морф `Fists` ранее был запечён в координаты и нормали. Раскрытие ладони и
моргание новым набором не добавляются.

Отдельные участки линейного скиннинга теряют объём при сильном сгибе. Новые
позы проверяются на швы, недостижимые цели и положение стоп, но это не гарантия
отсутствия всех самопересечений, особенно после добавления одежды.

## Почему без морфов внутри GLB

Ранее исходник проходил glTF Validator, но Godot падал при импорте варианта
с морфами. Поэтому морфы и старые клипы, двигавшие их веса, в прототип не
возвращались. Новые движения — отдельные нативные **скелетные** треки `.tres`.
Успешный импорт safe GLB и исполнение этих треков проверены в Godot 4.7.2 headless.

## Что делает существующий sanitizer

1. Запекает морф кулака в геометрию и нормали.
2. Убирает blend shapes и морфовые анимации.
3. Исправляет чужие влияния кистей/предплечий на ноги и торс.
4. Усредняет веса совпадающих вершин на швах.

Таким образом, старое описание «только удаляет анимации и не трогает веса»
уже не соответствовало коду. **Для правки новых анимаций sanitizer запускать
не требуется.** Это отдельная стадия работы с моделью, не генератор клипов.

Если действительно нужна повторная подготовка GLB, из корня репозитория:

```sh
python prototype/assets/heroine/sanitize_glb.py models/heroine/female_A_rigged.glb prototype/assets/heroine/female_A_rigged_safe.glb
```

После изменения модели нужно пересобрать библиотеку и заново проверить
деформации. Условия использования компонентов модели и исходные материалы —
в [`models/heroine`](../../../models/heroine/README.md).
