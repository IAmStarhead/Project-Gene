# Платье и облегающая форма испытуемого

`lab_uniform.json` — общий воспроизводимый ресурс Godot и диагностического JS:
сохранённое платье (`gown` + `cloth`), облегающий комбинезон (`suit`), морф
`RelaxedHands` и реальные опорные вершины стоп. Модель/скелет не заменяются.

- По умолчанию платье. **O** меняет одежду игрока **и клона**.
- **O / «Костюм»** в витрине читает тот же ресурс; выбор сохраняется между
  игрой и витриной в рамках сессии. Новый запуск снова начинает с платья.
- В диагностическом браузерном просмотрщике — список «Костюм». Полная кожа
  без одежды существует только для диагностики, не как новый игровой режим.
- Отдельный тренировочный манекен сохраняет собственное платье/функции.

## Новая форма испытуемого (правка 57)

[`lab_suit.py`](../../../tools/animation/lab_suit.py) сваривает совпадающие
позиции исходного тела, вырезает **одну связанную оболочку**, даёт локальную
прибавку 6 мм и ограниченное поверхностное сглаживание, затем заворачивает
пять краёв: шея, два запястья, две щиколотки. Топология промежности/пройм
сшита, не собрана из открытых независимых труб. Нет второй свободной кофты,
зазора на талии или пересекающихся поясов. Отступ от исходной поверхности
после fairing ограничен **9 мм**; это прибавка кроя, не расширение рукавов для
сокрытия заломов. В JSON сохранены исходные позиции/нормали для проверки.

**5 737 вершин / 10 956 треугольников**, обычный четырёхвесный skinned
ArrayMesh, прежний 21-костный Skin. Петрол/шалфей и охристая метка **07** —
собственный вариант для испытуемого, без копирования готового костюма Portal.
Палитра задаётся vertex colors, печать — мелкими криволинейными скиненными
панелями по поверхности ткани, не жёстким плавающим бейджем. Внешних текстур
и тяжёлого отдельного шейдера нет. Материал матовый; режим toon по-прежнему
не подменяет textile-меши.

У комбинезона **нет** отдельной cloth-симуляции; скрытый подол не обновляется.
У костюмов свои кешированные runtime-копии тела с тем же ручным морфом кистей.
Маска платья не расширена. У новой формы шея/запястья и 20 мм перекрытия кожи
сохранены; конец брючины поднят .125→.145 м, то есть скрывается **меньше** кожи.
Переключение не меняет коллайдер, ноги, скорость, атаку или фазу движения.

Это облегающий прототип посадки, **не финальная симуляция ткани**. LBS теряет
объём в сильных сгибах; произвольные self/hand/wall-контакты не исключены,
общей коллизии одежды с руками/стенами нет. Платье сохраняет прежнюю ограниченную
радиальную модель подола и его известные ограничения. Численные границы,
актуальная проверка деформаций/контактов и реальные кадры —
[отчёт 57](../../../../reports/57-форма-испытуемого-прыжок-и-удары-ногами.md).
[Историческая свободная белая форма и старые контакты, не новый комбинезон](../../../../reports/44-стрейф-костюмы-и-боевые-реакции.md).
Окончательное одобрение внешности остаётся за пользователем.

## Источники и воспроизведение

Внешняя готовая одежда, чужие игровые меши и AI-картинки не используются.
Геометрия производится из существующего `female_A_rigged_safe.glb` и кода
проекта. Для исходных MakeHuman-компонентов сохранены
[источники](../../../../models/heroine/README.md) и
[CC0](../../../../models/heroine/LICENSE_MAKEHUMAN_ASSETS.md).
Новых сторонних условий для костюма или оригинальных векторных значков
ударов не добавлено. Исходные GLB в `models/` не меняются.

Из корня репозитория (зависимости `tools/animation/requirements.txt`):

```sh
python prototype/tools/animation/build_appearance.py
python prototype/tools/animation/build_appearance.py --check
python -m unittest discover -s prototype/tools/animation -p 'test_*.py'
python prototype/tests/run_headless.py --godot /path/to/godot
```

`test_outfits.gd` проверяет переключение обоих актёров/витрины, настоящий Skin,
морф, клипы, точный возврат индексов платья и отсутствие обновлений скрытого
подола. Он сравнивает один и тот же двухактёрный набор в headless, печатая
**CPU**, не GPU/FPS ноутбука. `test_subject_and_kicks.py` защищает доправочный
хеш платья/масок/рук/опор и ограничение новой прибавки. `test_air_contact.gd`
независимо измеряет все низкие вершины обеих настоящих стоп, физический пол,
коллайдер и действительные прыжок/посадку, не замороженную стойку над полом.
