# Одежда испытуемой и сохранённое платье

`lab_uniform.json` — общий ресурс Godot и диагностического Three.js: топ и шорты (`suit`), сохранённое платье (`gown` + `cloth`), морф `RelaxedHands` и опорные вершины стоп. Исходные модель и скелет не заменяются.

В игре и витрине сейчас **только светлая форма**: топ без рукавов и короткие шорты, слегка облегающие, два скелетных участка одного меша. Платье временно недоступно через интерфейс и O, но его ресурс, код и диагностические тесты сохранены. Игрок, клон и разрезаемый манекен используют форму. В отдельном Motion Lab платье оставлено для диагностики, это не игровой переключатель.

`prototype/tools/animation/lab_suit.py` вырезает два участка из исходной поверхности и назначает скин-веса. Локальный нормальный отступ 11 мм, ограничение 16 мм; проймы, шея, низ топа, пояс и края шорт обработаны. Маска кожи сохраняет открытые руки, ноги, талию и перекрытие у краёв. Это skinned mesh, **не физическая ткань**: автоматическая проверка конечных координат не гарантирует отсутствия пробоев при движении. Физика груди и ягодиц отдельно в риге не реализована; они следуют позе костей.

Источники и лицензии базовой модели: [модель](../../../../models/heroine/README.md), [лицензия](../../../../models/heroine/LICENSE_MAKEHUMAN_ASSETS.md). Новых внешних моделей или текстур нет. История предыдущего варианта и его незакрытых проблем — [отчёт второго агента](../../../../reports/57-форма-испытуемого-прыжок-и-удары-ногами.md), текущая проба — [отчёт 59](../../../../reports/59-топ-шорты-и-физика.md).

Для воспроизведения (зависимости `tools/animation/requirements.txt`):

```sh
python prototype/tools/animation/build_appearance.py
python prototype/tools/animation/build_appearance.py --check
python -m unittest discover -s prototype/tools/animation -p 'test_*.py'
python prototype/tests/run_headless.py --godot /path/to/godot
```
