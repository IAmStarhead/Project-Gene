# Два лабораторных костюма

`lab_uniform.json` — общий авторский ресурс Godot и диагностического JS:
платье (`gown` + `cloth`), закрытая форма (`suit`), морф `RelaxedHands` и
настоящие опорные вершины стоп. Модель/скелет не заменяются.

- **По умолчанию платье. O** в игре переключает одежду игрока **и клона**.
- **O / кнопка «Костюм»** в витрине меняет тот же ресурс; выбор сохраняется
  между игрой и витриной в рамках сессии. Новый запуск снова начинает с платья.
- В необязательном браузерном просмотрщике — список «Костюм». Полная кожа
  без одежды существует только как диагностический просмотр, не игровой режим.

## Форма

[`lab_suit.py`](../../../tools/animation/lab_suit.py) воспроизводимо сваривает
UV-копии поверхности исходного тела, вырезает и сшивает топ и длинные штаны,
даёт умеренную прибавку и выпрямляет панели голеней. Проймы и промежность —
не открытые независимые трубы. Ворот, запястья, талия и щиколотки имеют
настоящий край/узкую обтачку; топ перекрывает пояс. Небольшая ID-метка
интерполирует веса ткани под собой. Матовые белый/светло-серый vertex colors,
без тяжёлого шейдера, текстурной зависимости, брони или открытого живота.

Это обычный **четырёхвесный skinned ArrayMesh**, тот же 21-костный Skin.
У формы **нет** отдельной cloth-симуляции; скрытый подол не обновляется.
У каждого костюма своя кешированная runtime-копия тела с тем же ручным
морфом кистей. Маска платья не расширена. Маска формы относится только к
реально закрытым длинным рукавам/брюкам и оставляет 20 мм кожи за краями.
Переключение не меняет коллайдер, ноги, скорость, атаку или фазу движения.

Это прототип посадки, не обещание отсутствия самопересечений на произвольных
позах. У плеча/проймы остаются заломы и геометрические контакты,
у промежности — упрощённое натяжение. В нескольких фазах jog/sprint/dodge
FCL фиксирует foot/toe у края брюк; это **не** автоматически невидимые
контакты. [Крупные диагностические кадры и все числа](../../../../reports/44-стрейф-костюмы-и-боевые-реакции.md).
Выбор окончательного костюма и эстетики остаётся за пользователем.

## Источники и воспроизведение

Внешняя готовая одежда, чужие игровые меши или AI-картинка не используются.
Геометрия производится из существующего `female_A_rigged_safe.glb` и кода
проекта. Для исходных MakeHuman-компонентов в репозитории сохранены
[источники](../../../../models/heroine/README.md) и
[CC0](../../../../models/heroine/LICENSE_MAKEHUMAN_ASSETS.md).
Новых сторонних условий для костюма не добавлено.

Из корня репозитория (зависимости из `tools/animation/requirements.txt`):

```sh
python prototype/tools/animation/build_appearance.py
python prototype/tools/animation/build_appearance.py --check
python -m unittest discover -s prototype/tools/animation -p 'test_*.py'
python prototype/tests/run_headless.py --godot /path/to/godot
```

Нативный `test_outfits.gd` проверяет переключение обоих актёров/витрины,
настоящий Skin, морф, клипы, точный возврат индексов платья и отсутствие
обновлений скрытого подола. Он сравнивает один и тот же двухактёрный набор
поз в headless и явно печатает **CPU**, не GPU/FPS ноутбука.
