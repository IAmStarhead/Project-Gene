# Библиотека движений героини

- `motion_set.tres` — нативная Godot `AnimationLibrary`, 11 клипов.
- `motion_set.json` — те же ключи и метаданные для браузера/геометрических тестов.

Оба файла генерируются из `prototype/tools/animation/build_motion_set.py`.
Править их вручную не нужно. Они предназначены для существующего
`female_A_rigged_safe.glb` (21 кость); SHA-256 модели записан в JSON.

**Игра, клон и витрина Godot используют одну `.tres`.** Исходный GLB, его
топология, веса и материалы при создании этой библиотеки не менялись.
Сторонние анимации и Blender не использовались.
