# Gen — игровой прототип и анимации

**Godot 4.7.2 · Compatibility (OpenGL 3.3).** Тестовая комната, не готовая
игра: героиня с 21-костным скелетом, клон-противник, три темпа передвижения,
обычная/боевая стойка, прыжок, два удара, направленные увороты и **18 клипов**.
На героине и клоне — закрытое светло-серое лабораторное платье.

## Запуск через GitHub Desktop

1. **Fetch origin**, выбрать рабочую ветку **`arena/d65c076f-project-gene`**
   (или `arena/320aeafc-project-gene` при проверке отдельных правок анимаций),
   затем **Pull origin**. Не запускать старую копию `main`.
2. В Godot 4.7.2 выбрать **Импорт → `prototype/project.godot`**.
3. Дождаться импорта модели и нажать **F5**.
4. Нажать **F3**, чтобы увидеть точный FPS, время кадра и активную видеокарту
   (должна быть `NVIDIA GeForce 940MX`, а не встроенная графика Intel).
5. Для просмотра отдельных движений — **H** или пункт «Витрина анимаций» в меню **Esc**.

**Blender, Python и Node.js для игры не нужны.** Готовые
`assets/heroine/animations/motion_set.tres` и `assets/heroine/appearance/lab_uniform.json`
уже в репозитории. Кэш `.godot/` создаётся локально, не добавляйте его в Git.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD + **удерживать Left Alt** | спокойная ходьба, **1.15 м/с** |
| WASD **без модификаторов** | лёгкий бег, **2.9 м/с** |
| WASD + **удерживать Shift** | быстрый бег, **5.6 м/с** |
| Мышь | камера независимо от поворота тела |
| ЛКМ / ПКМ | удар левой / правой рукой |
| Пробел + направление | уворот вперёд/назад/вбок/по диагонали без разворота тела |
| Пробел без направления | уворот назад относительно тела |
| F | прыжок |
| Tab или **СКМ** (колёсико) | захват цели / снятие захвата |
| Прокрутка колёсика (в захвате) | смена цели слева / справа на экране |
| R | обычная / боевая стойка игрока |
| T | включить / выключить бой клона |
| H | витрина анимаций |
| Esc | меню паузы (графика, свет, стиль, витрина, выход) |
| **F4** | пресет качества графики: низкое / среднее (940MX) / высокое |
| B | яркость зала: приглушённо / штатно / ярко |
| G | стиль персонажей: полуреализм (по умолчанию) / селлшейдинг |
| F3 | честная диагностика: FPS, мс кадра, активная видеокарта, отрисовка, попадания |

**Shift имеет приоритет**, если одновременно зажаты Shift и Left Alt.
Правый Alt / AltGr не является кнопкой спокойной ходьбы.
Три модификатора одинаково задают скорость игрока в обеих стойках; R меняет
позу/защиту, а не смысл Alt и Shift. Клон сохраняет собственную калибровку ИИ.

Игра начинается в обычном режиме: руки опущены, пальцы действительно разжаты
до мягкой формы. R или **Esc → Режим игрока** меняет стойку без сброса шага.
Удар или полученный урон включает бой; выйти — R. **T управляет только клоном.**
При атаке кисти сжимаются до активного кадра.

Три обычных цикла различаются не только темпом: двойная опора и перекат при
шаге, короткая опора/полёт при лёгком беге, более сильный толчок и перенос ноги
при быстром. Двигаются таз, позвоночник, грудь, ключицы, голова, руки и стопы.
Локоть мягко складывается на переднем махе и раскрывается на обратном; низкая
дуга кисти проходит снаружи текущего подола, а не остаётся перед животом.
Голова сохраняет взгляд, но больше не удерживается в почти неподвижном мировом
вращении: шея сглаживает небольшой запаздывающий кивок и поворот.
Фаза следует реальным метрам после `move_and_slide()`. Подошва дополнительно
проверяется после смешивания — сами по себе безопасные клипы могли проседать
на переходах.

Уворот переработан: **0.48 с / 1.10 м** на свободном ровном полу, с загрузкой,
толчком, раздельными контактами ног и восстановлением. Дистанция проверена
при 30/60/120 Гц; стены ограничивают перемещение обычной физикой.
Окна урона/неуязвимости, стамина и вертикальная физика прыжка сохранены.

## Одежда

Общий светло-серый крой: закрытые перед/спина, короткие рукава, узкий светлый
кант и метка. Плечи и подмышки — одна поверхность по существующей модели,
а не отдельные раздутые эллипсы. У клона слегка холоднее материал.
Реальная кожа руки продолжается под манжетой; широкий вырез заменён маленькой
закрытой сердцевиной подмышки с 53 мм перекрытия до края рукава.
Исходные GLB и мягкая форма кистей не менялись.

Верх следует скелету. У каждого актёра **свои 320 точек подола (32×10)**,
динамика до **2.5 см**, капсулы ног и объём таза. Контакт проверяется и между
узлами — в центрах ячеек, поддерживающих треугольники перед коленом.
Подол не раздувается вокруг половины юбки и не выворачивается на уворотах.
Шов талии совпадает геометрией и нормалями, без отдельной серой полосы.

Это ограниченная визуальная модель, **не полноценный cloth**: нет общей
самоколлизии, контактов с руками/стенами, разрывов и влияния на физику тела.
FCL не нашёл пересечений юбки с видимым телом на 848 записанных кадрах + 4
точных seek; **на лифе/рукавах пересечения остаются**. Отсутствие всех возможных
пересечений не гарантируется; подробности и CPU-стоимость — в отчёте 37.

## Витрина Godot

Слева — **18 клипов**, включая спокойный шаг, лёгкий и быстрый бег, четыре уворота.
Внизу — пауза, покадровые кнопки, 0.25× / 0.5× / 1× и ползунок времени.
Сверху — спереди / сбоку / сзади / ¾.

- Пробел — воспроизведение / пауза; ← / → — кадр; ↑ / ↓ — клип.
- L — скорость; R — камера по умолчанию.
- ЛКМ + мышь — орбита; колесо — масштаб; Esc / H — в игру.

Витрина читает ту же библиотеку и одежду. Модификаторы, переходы, полный
физический прыжок и диагональные увороты проверяйте также в комнате на F5.

## Где менять и как проверять

- `scripts/tuning.gd` — скорости, стамина, тайминги, камера.
- `tools/animation/locomotion.py` — три обычных цикла и координация корпуса.
- `tools/animation/build_motion_set.py` — остальные движения и запекание.
- `tools/animation/garment.py` — непрерывный крой лифа/рукавов, обтачки и шов.
- `tools/animation/build_appearance.py` — подол, кисти, опорные точки подошвы.
- `scripts/character_anim.gd` — нативный сэмплер/блендер и коррекция подошвы.
- `scripts/character_appearance.gd` — руки после импорта, материал, покрытие и подол.
- `scripts/player.gd`, `scripts/clone_enemy.gd` — физика и окна урона.

С установленным Godot, из корня репозитория:

```sh
python prototype/tests/run_headless.py --godot /path/to/godot
```

Проверяются нативные треки, Alt/Shift и их приоритет, режимы/R/T/меню, реальные
скорости, подошва импортированного меша, удары, прыжки, стена, увороты и ткань
при 30/60/120 Гц. Проверяются и код возврата, и ошибки в логе.
Авторинг/офлайн-тесты — [в инструкции](ANIMATIONS.md); необязательная
[браузерная витрина](animation_preview/README.md) не нужна для F5.

## Границы проверки

Это прототип, не финальный mocap-набор или утверждённый костюм. Нет terrain IK,
жёсткой фиксации стоп при развороте, оружейных комбо, блока и рига пальцев.
Увороты — быстрые уходы, не root-motion перекаты. Переходы и естественность
нужно оценивать в движении на 1×; численные регрессии не заменяют эту оценку.

**GPU-рендер Godot и FPS на GeForce 940MX здесь не измерялись.** Позы, физика,
кисти и точки подола записаны в headless Godot; ролик отрисован Three.js,
не снят с окна игры. Особенность custom-бинарника при fresh import раскрыта
в отчётах 31–32.
