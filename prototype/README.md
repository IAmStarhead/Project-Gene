# Gen — объединённый прототип 0.0.3

**Godot 4.7.2 · Compatibility.** Белая лаборатория, героиня и тренировочный
клон на существующем 21-костном риге, три темпа, обычная/боевая стойка,
прыжок, четыре уворота, джеб/кросс, HUD и захват цели. **18 клипов**.
По умолчанию — PBR-персонажи и закрытое светло-серое лабораторное платье.
Это тестовая комната, не готовая игра.

## Запуск через GitHub Desktop

1. **Fetch origin**, выбрать **`arena/320aeafc-project-gene`**, затем **Pull origin**.
   Не запускать старую копию `main`.
2. В Godot 4.7.2 выбрать **Импорт → `prototype/project.godot`**.
3. Дождаться импорта модели и нажать **F5**.
4. **F3** показывает фактический адаптер, время кадра и параметры текущего
   запуска. Для проверки 940MX убедитесь, что выбрана NVIDIA, а не Intel.
5. **H** или **Esc → Витрина анимаций** — отдельные движения; также можно
   открыть `scenes/showcase.tscn` и запустить через **F6**.

**Blender, Python и Node.js для F5 не нужны.** Готовые GLB, библиотека TRES
и `appearance/lab_uniform.json` включены. Кэш `.godot/` создаётся локально,
в Git его добавлять не нужно. Исходники в `models/` сохранены.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD + **удерживать Left Alt** | спокойная ходьба, **1.15 м/с** |
| WASD без модификаторов | лёгкий бег, **2.9 м/с** |
| WASD + **удерживать Shift** | быстрый бег, **5.6 м/с** |
| Мышь | независимая камера |
| ЛКМ / ПКМ | левый джеб / правый кросс |
| Пробел + направление | уворот вперёд/назад/вбок/по диагонали |
| Пробел без направления | уворот назад относительно тела |
| F | прыжок |
| **Tab / СКМ** | захват / снятие захвата цели |
| Колесо в захвате | смена цели слева/справа на экране |
| R | обычная / боевая стойка игрока |
| T | бой клона: ВЫКЛ / ВКЛ; не меняет стойку игрока |
| H | игра ↔ витрина |
| Esc | пауза, графика, свет, стиль, витрина, выход |
| **F4** | низкое / среднее / высокое качество |
| B | приглушённый / штатный / яркий свет |
| G | PBR / селлшейдинг персонажей |
| F3 | подробная диагностика FPS/адаптера, стойки, захвата и контакта |

Shift приоритетнее Left Alt; Right Alt / AltGr не включает шаг. R меняет
стойку, **не скорости** Alt/без кнопок/Shift. Игра начинается в обычной стойке,
с мягко раскрытыми кистями. Удар или полученный урон включает бой; выйти — R.
Пальцы сжимаются до активного кадра; это ручной морф, не риг пальцев.

**Без захвата** остаётся свободное движение с разворотом к направлению,
в том числе в боевой стойке. **С захватом** корпус и камера следуют цели;
ввод переводится в оси цели. Но ноги пока используют прежние циклы, а не
новые боковые/задний шаги. Это сохранённый lock-on, **не выполненный этап
стрейфа** из поручения 42. Потеря/смена цели, смерть и стена проверены отдельно.

Фаза шага следует реальному перемещению после `move_and_slide()`; у стены
не должна прокручиваться как при свободном беге. Принятые четыре обычных
клипа сохранены целиком. Прыжок, уворот **0.48 с / 1.10 м**, окно
неуязвимости, стамина, скорости и тайминги ударов не перенастраивались.

`hit_check.gd` уже оценивает `head / torso / legs` по упрощённой геометрии;
F3 показывает эту оценку. **Это не точные анатомические хитбоксы.** Зона
пока не передаётся в выбор реакции: `take_damage(amount, direction)` и
`play_hit()` сохраняют прежний контракт. Декоративная отдача не добавляет стан.

## Платье и оставшиеся ограничения

Общий светло-серый крой: закрытые перед/спина, короткий рукав, светлый кант
и метка; у клона немного холоднее материал. Верх следует скелету. Маска кожи
не расширена и рукав не увеличен ради скрытия дефектов. В игре **нет полной
диагностической кожи**; восстановление исходных индексов использовалось только
в изолированных проверках плеча.

У каждого актёра независимые **320 точек подола (32×10)**, шаг 60 Гц,
вторичная динамика до **12 мм**, объём таза и поддержка капсулами ног между
узлами. Подол поднимается над коленом, а не удерживается на фиксированной высоте.
Шов талии согласован по позиции и нормалям. Это **не полноценный cloth**:
нет общей самоколлизии, контактов с руками/стенами, разрывов или обратного
влияния на физику тела. Локальные рёбра всё ещё заметно растягиваются;
лиф/рукава имеют оставшиеся контакты. Небольшие заломы плеча и острые участки
подола ещё требуют художественной доработки. Числа FCL, сравнения и настоящее
видео Godot — в [отчёте 43](../reports/43-интеграция-и-ремонт-после-поручения-42.md).

## Витрина Godot

Слева — все **18 клипов** общей AnimationLibrary; внизу — транспорт,
пауза, кадр, 0.25× / 0.5× / 1× и ползунок времени. Сверху — фронт/бок/спина/¾,
«Весь рост» и UI. Интерфейс адаптируется к окну; голова и стопы вписываются
в свободную область, не под панели. Камера ограничена стеной/полом.

- Пробел — пауза; ← / → — кадр; ↑ / ↓ — клип; L — скорость.
- R — сброс камеры; **V — скрыть/вернуть UI**.
- ЛКМ + мышь — орбита; колесо — масштаб, отключает автокадрирование.
- «Весь рост» возвращает автокадрирование; B / F4 / G меняют студийный
  свет/качество/стиль, не возвращают случайно игровой свет.
- H / Esc — в игру. Физический прыжок, переходы и модификаторы проверяйте и в F5.

## Проверки и исходники

```sh
python prototype/tests/run_headless.py --godot /path/to/godot
```

Запускаются **606 прежних + 55 интеграционных проверок**. Проверяются код
возврата, завершение обеих suites и ошибки Godot в логе; старые допуски
не ослаблены. Новая suite проверяет совместную сцену, материал PBR/toon,
HUD/lock-on, приближённый hit-check, смерть/респаун, студийный свет и readback
реально отображаемой юбки спящего поворачивающегося клона.

Python — **43 теста**, оба генератора имеют `--check`; команды и зависимости —
[в ANIMATIONS.md](ANIMATIONS.md). `tests/record_motion.gd` и `record_garment.gd`
записывают реальные позы/ткань с SHA исходников. Необязательная
[Three.js-витрина](animation_preview/README.md) не нужна для игры и не является Godot.

## Границы проверки

Проверено на доступном **custom Godot 4.7.2**: нативная headless-логика и
Compatibility/WebGL2 со SwiftShader. На нём fresh import создаёт ресурсы,
но выдаёт ошибки отсутствующего в сборке fontconfig: **строгий чистый импорт
не засчитан**, проверка ошибок не отключена. `--skip-import` предназначен
только для уже импортированного проекта, не для сокрытия ошибки импорта.

**Официальная Windows/OpenGL 3.3-сборка и GeForce 940MX здесь не проверялись.**
FPS браузера/headless не переносится на ноутбук. Настоящие кадры Godot не
означают запись 60 уникальных кадров/с: частота и повторение кадров ролика
раскрыты в отчёте. Нет terrain IK, жёсткой фиксации стоп при развороте,
оружейных комбо, блока или полноценной зональной боевой системы.
