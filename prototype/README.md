# Gen — игровой прототип и анимации

**Godot 4.7.2 · Compatibility (OpenGL 3.3).** Тестовая комната, не готовая
игра: героиня с 21-костным скелетом, клон-противник, обычное/боевое движение,
прыжок, два удара, направленные увороты и **17 анимационных клипов**.
Героиня и клон одеты в закрытое лабораторное платье с подвижным подолом.

## Запуск

1. В GitHub Desktop получить изменения ветки **`arena/320aeafc-project-gene`**:
   **Fetch origin → эта ветка → Pull origin**. Не запускать старую копию `main`.
2. В Godot выбрать **Импорт → `prototype/project.godot`**.
3. Дождаться импорта модели и нажать **F5**.
4. Для проверки отдельных движений — **H** или витрина в меню **Esc**.
   Можно открыть `scenes/showcase.tscn` и запустить через **F6**.

**Blender, Python и Node.js для запуска игры не нужны.** Готовые
`assets/heroine/animations/motion_set.tres` и `assets/heroine/appearance/lab_uniform.json`
уже в репозитории. Кэш `.godot/` создаётся локально; в Git его добавлять не надо.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD | движение относительно камеры |
| Мышь | камера, независимо от поворота тела |
| Shift | бег |
| ЛКМ / ПКМ | удар левой / правой рукой |
| Пробел + направление | уворот вперёд/назад/вбок/по диагонали без разворота тела |
| Пробел без направления | уворот назад относительно тела |
| F | прыжок |
| R | обычная / боевая стойка игрока |
| T | включить / выключить бой клона |
| H | витрина анимаций |
| Esc | меню паузы |
| B / G | яркость / селлшейдинг |
| F3 | подробная отладка |

Игра начинается в **обычном режиме**, с опущенными руками и действительно
разжатыми, слегка согнутыми пальцами. **R** или **Esc → Режим игрока** меняет
стойку без сброса фазы шага. Удар или полученный урон включает бой; выйти — R.
**T управляет только клоном.** Во время удара кисти сжимаются до активного кадра.

Обычные скорости — **1.35 / 3.8 м/с**, боевые сохранены **1.65 / 4.6 м/с**.
В обычном режиме это примерно **121 / 172 шага в минуту**, а не прежние
160 / 230. Меняются не только скорость клипа и руки: у обычного бега свой цикл
ног. Фаза по-прежнему следует реальному перемещению после `move_and_slide()`.
Уворот длится 0.42 с и проходит около 1.40 м на свободном ровном полу при 60 Гц.
Стамина, окна урона/неуязвимости и вертикальная физика прыжка сохранены.

## Одежда

На обоих персонажах один крой: закрытые перед/спина, короткие рукава, кант,
пояс и маленькая метка испытуемой. У клона более холодный оттенок ткани.
Верх следует скелету; у каждого персонажа **свои 112 точек подола**.
Есть ограниченное вторичное движение и аналитические столкновения с тазом
и ногами. Это лёгкая визуальная модель ткани, **не полноценная симуляция cloth**:
нет самоколлизии, столкновений с руками/стенами, разрывов и влияния на физику тела.

## Витрина Godot

Слева — **все 17 клипов**, в том числе четыре направления уворота.
Внизу — пауза, покадровые кнопки, 0.25× / 0.5× / 1× и ползунок времени.
Сверху — спереди / сбоку / сзади / ¾.

- **Пробел** — воспроизведение / пауза.
- **← / →** — кадр; **↑ / ↓** — клип.
- **L** — скорость; **R** — камера по умолчанию.
- ЛКМ + мышь — орбита; колесо — масштаб; **Esc / H** — в игру.

Витрина читает ту же библиотеку и ту же одежду, что игра. Полный физический
прыжок и диагональные увороты проверять также в комнате, не только по клипам.

## Где менять и как проверять

- `scripts/tuning.gd` — обычные/боевые скорости, стамина, тайминги, камера.
- `tools/animation/build_motion_set.py` — траектории и запекание движений.
- `tools/animation/build_appearance.py` — геометрия платья и форма мягкой кисти.
- `scripts/character_anim.gd` — выбор, сэмплирование и смешивание клипов.
- `scripts/character_appearance.gd` — руки после импорта, материал и подол.
- `scripts/player.gd`, `scripts/clone_enemy.gd` — физика и окна урона.

Из корня репозитория с установленным Godot:

```sh
python prototype/tests/run_headless.py --godot /path/to/godot
```

Проверяются импорт, нативные треки, режимы и реальные скорости игрока,
R/T/меню, удары, прыжки, стена, направление/взгляд при увороте, настоящая форма
кистей и подол при 30/60/120 FPS. Утилита проверяет и код возврата, и ошибки лога.
Офлайн-генераторы и тесты — [в инструкции](ANIMATIONS.md); необязательная
[браузерная витрина](animation_preview/README.md) не нужна для F5 в Godot.

## Ограничения

Это прототип, не финальный mocap-набор или утверждённый дизайн костюма.
Нет оружейных комбо, блока, отдельных смертей и рига отдельных пальцев.
Увороты — короткие уходы/подшаги, не полноценные root-motion перекаты.
Стопы рассчитаны для плоскости: нет terrain IK; при резких поворотах возможен сдвиг.
Столкновения ткани приближённые и не гарантируют отсутствие всех пересечений.

**GPU-рендер Godot и FPS на GeForce 940MX здесь не измерялись.** Нативные
позы, физика, кисти и точки подола проверены headless; видеопроверка отрисована
в Three.js, не снята с окна Godot. Свет и материалы остаются прототипными.
