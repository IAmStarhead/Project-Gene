# Gen — объединённый прототип 0.0.3

**Godot 4.7.2 · Compatibility.** Белая лаборатория, героиня и тренировочный
клон на существующем 21-костном риге, **39 общих клипов**, три темпа,
направленное движение под lock-on, два костюма, прыжок, четыре уворота,
джеб/кросс, Q-хук, декоративные реакции головы/корпуса, HUD и захват цели.
По умолчанию — PBR и сохранённое лабораторное платье. Это тестовая комната,
не готовая игра и не финальный дизайн персонажа.

## Запуск через GitHub Desktop

1. **Fetch origin**, выбрать **`arena/320aeafc-project-gene`**, затем **Pull origin**.
   Не запускать старую копию `main`.
2. В Godot 4.7.2 выбрать **Импорт → `prototype/project.godot`**.
3. Дождаться импорта модели и нажать **F5**.
4. **F3** показывает фактический адаптер, время кадра, стойку, костюм и контакт.
   Для замера 940MX убедитесь, что действительно выбрана NVIDIA, а не Intel.
5. **H** или **Esc → Витрина анимаций** — отдельные клипы; также можно
   открыть `scenes/showcase.tscn` и запустить **F6**.

**Blender, Python и Node.js для F5 не нужны.** GLB, AnimationLibrary TRES и
`appearance/lab_uniform.json` включены. Кэш `.godot/` создаётся локально,
в Git не нужен. Исходные модели в `models/` сохранены.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD + **удерживать Left Alt** | спокойный шаг, **1.15 м/с** |
| WASD без модификаторов | лёгкий бег, **2.9 м/с** |
| WASD + **удерживать Shift** | свободный / направленный вперёд спринт, **5.6 м/с**; под захватом вбок/назад **3.4 м/с** |
| Мышь | независимая камера |
| ЛКМ / ПКМ | прежние левый джеб / правый кросс |
| **Q** | короткий **левый хук в корпус** |
| Пробел + направление | уворот вперёд/назад/вбок/по диагонали |
| Пробел без направления | уворот назад относительно тела |
| F | прыжок |
| **Tab / СКМ** | захват / снятие захвата цели |
| Колесо в захвате | смена цели слева/справа на экране |
| R | обычная / боевая стойка игрока |
| T | бой клона ВЫКЛ / ВКЛ; не меняет стойку игрока |
| **O** | платье ↔ закрытый топ с длинными штанами, **оба персонажа** |
| H | игра ↔ витрина |
| Esc | пауза, графика, свет, стиль, витрина, выход |
| F4 | низкое / среднее / высокое качество |
| B / G | яркость / PBR ↔ селлшейдинг персонажей |
| F3 | диагностика FPS/адаптера, движения, костюма, зоны и источника контакта |

Shift приоритетнее Left Alt; Right Alt / AltGr не включает шаг. R меняет
стойку, а не три свободные скорости. Игра начинается в обычной стойке,
с мягко раскрытыми кистями. Атака или полученный удар включает бой; выйти — R.
Пальцы сжимаются до активной фазы; это настоящий ручной морф, не риг пальцев.

**Без захвата обе стойки свободно разворачиваются к движению.** С захватом
корпус следует цели, ноги используют отдельные циклы вперёд/влево/вправо/назад,
диагонали смешивают соседние направления с общей фазой опоры. Ориентир —
фактическое перемещение относительно тела после `move_and_slide()`, не WASD.
У стены фаза останавливается; при скольжении используется касательная скорость.
Lock-on сам по себе не включает R: в обычной стойке руки остаются раскрытыми.

Направленный Shift вбок/назад ограничен **3.4 вместо 5.6 м/с**: это
собранный шаг лицом к цели, не боковой атлетический спринт. Вперёд — 5.6;
под 45° вперёд-вбок — 4.5; назад-вбок — 3.4. Alt/обычный бег сохраняют
1.15/2.9, диагонального ускорения нет. Принятые четыре обычных клипа, ноги,
прыжок, уворот **.48 с / 1.10 м**, i-frames и прежние параметры прямых сохранены.

Q отдельно согласован: **.22 + .10 + .30 = .62 с**, активно **.22–.32**,
вылет ≤.60 м, урон/стамина **18/18**. Старые ЛКМ/ПКМ — .18/.12/.26,
.72 м, 24/18. Клон не получил скрытую Q-атаку. Зона и WORLD-направление
подтверждённого упрощённого контакта выбирают отдачу головы/корпуса;
это **не анатомические хитбоксы**, не дополнительный стан/урон.
Для ног пока только ослабленная общая отдача верха. [Подробности](COMBAT.md).

## Одежда и оставшиеся ограничения

Сессия начинается с платья; **O** переключает настоящую геометрию и сохраняет
выбор между игрой/витриной. Новый запуск снова начинает с платья. У клона
свой холодный оттенок материала. Маска платья не расширена; полная кожа с
исходными индексами существует **только в изолированной диагностике**.

- Платье: непрерывные лиф/рукава, **320 независимых точек подола на актёра**,
  шаг 60 Гц, вторичное движение до 12 мм, поддержка объёмом таза и капсулами ног.
  Материал поднимается над коленом, шов талии согласован по позиции/нормалям.
  Новое сглаживание 32 узлов границы уменьшило заострение на 14–35% в четырёх
  трудных позах, но подняло медиану расчёта **18.05→27.74 мс CPU/актёр** в
  headless. Это осознанный компромисс прототипа, не гарантия FPS на ноутбуке.
- Форма: настоящий skinned-меш закрытого топа/брюк, тот же риг/мягкие кисти,
  умеренные швы и ID-метка. Отдельной симуляции штанов нет; скрытый подол не
  рассчитывается. Устранены растянутая внутренняя обтачка и явный пробой талии.
- **Не полноценный cloth:** нет общей самоколлизии, cloth/hand/wall collision,
  разрывов или обратного влияния на физику. Острые участки подола, условное
  натяжение и контакты проймы/нижних краёв брюк остаются. Ноль пересечений
  юбки в записанной выборке не означает отсутствие всех видимых дефектов.

## Витрина Godot

Все **39 клипов** общей библиотеки: 18 прежних + 12 направленных + Q + 8
реакций. Пауза, кадр, .25×/.5×/1×, ползунок; фронт/бок/спина/¾ и «Весь рост».
Интерфейс вписывает голову/стопы в свободную область, камера ограничена стенами.

- Пробел — пауза; ←/→ — кадр; ↑/↓ — клип; L — скорость.
- **O / «Костюм»** — одежда; **V** — UI; R — сброс камеры.
- ЛКМ + мышь — орбита; колесо — масштаб; «Весь рост» — автокадрирование.
- B / F4 / G — свет/качество/стиль. H / Esc — обратно в игру.

Переходы, физический прыжок, модификаторы и подтверждённые попадания проверяйте
**также в F5**, не только точными seek в витрине.

## Проверки и среда

```sh
python prototype/tests/run_headless.py --godot /path/to/godot
```

Текущий строгий прогон: **1485 проверок / 0 ошибок**, строгий импорт
и шесть suites; Python **56/56**, оба генератора `--check` совпали.
Расширенный animation-набор занимает около 243 с: таймаут — 300 с на suite,
ни одна проверка не отключена. Отдельно прошли семь тестов review-tools.
Браузерная дополнительная витрина: 39 клипов / 312 поз; живой JS/native
решатель: 1467 кадров + 18 seek, максимум **.0254 мм** при допуске .25 мм.
Команды авторинга — [ANIMATIONS.md](ANIMATIONS.md), запись настоящих Godot
кадров — [отдельный harness](tests/rendered_review/README.md).

Проверено на доступном **custom Godot 4.7.2**: нативная headless-логика и
Compatibility/WebGL2 / Chromium ANGLE SwiftShader. Ошибка compiled-out
fontconfig устранена пересборкой локального движка; проверки логов не ослаблялись.
**Официальная Windows/OpenGL 3.3-сборка и GeForce 940MX здесь не проверялись.**
CPU headless и FPS SwiftShader не переносятся на ноутбук. Ролики 44 — реальный
контроллер, 60 Гц физики / **10 записанных кадров/с / 1×**, не 60 уникальных FPS.
Нет terrain IK, жёсткой фиксации стоп при развороте, оружейных комбо или блока.
