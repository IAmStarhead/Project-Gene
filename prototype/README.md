# Gen — игровой прототип и анимации

**Godot 4.7.2 · Compatibility (OpenGL 3.3).** Это тестовая комната, не готовая
игра. В ней уже есть героиня с 21-костным скелетом, клон-противник, движение,
прыжок, два удара, уклонение и **14 анимационных клипов** с обычным и боевым
передвижением.

## Запуск

1. В Godot выбрать **Импорт → `prototype/project.godot`**.
2. Дождаться первого импорта модели и нажать **F5**.
3. Для проверки анимаций нажать **H** или выбрать витрину в меню **Esc**.
   Можно также открыть `scenes/showcase.tscn` и запустить её через **F6**.

**Blender, Python и Node.js для запуска игры не нужны.** Готовая библиотека
`assets/heroine/animations/motion_set.tres` уже в репозитории. Кэш `.godot/`
создаётся локально, добавлять его в Git не следует.

## Управление в игре

| Ввод | Действие |
| --- | --- |
| WASD | движение относительно камеры |
| Мышь | камера, независимо от поворота тела |
| Shift | бег |
| ЛКМ / ПКМ | удар левой / правой рукой |
| Пробел | уклонение-рывок по направлению ввода |
| F | прыжок |
| R | обычная / боевая стойка игрока |
| T | включить / выключить бой клона |
| H | витрина анимаций |
| Esc | меню паузы |
| B / G | яркость / селлшейдинг |
| F3 | подробная отладка |

Игрок начинает в **обычном режиме**, с опущенными руками. **R** или
**Esc → Режим игрока** переключает стойку плавно, без сброса шага. Удар
ЛКМ/ПКМ или полученный урон включает бой; для выхода нажать R. **T управляет
только клоном.** Скорость, стамина, физика и принятые боевые клипы не менялись.

## Витрина Godot

Слева — **все 14 клипов** в прокручиваемом списке, а не отдельные
приблизительные позы. Внизу — пауза, покадровые кнопки, скорость 0.25× / 0.5× / 1× и ползунок времени.
Сверху — ракурсы спереди, сбоку, сзади и ¾.

- **Пробел** — воспроизведение / пауза.
- **← / →** — кадр назад / вперёд; **↑ / ↓** — предыдущий / следующий клип.
- **L** — скорость; **R** — камера по умолчанию.
- Зажать ЛКМ и двигать мышь — орбита; колесо — масштаб.
- **Esc / H** — вернуться в игру.

Для атаки отмечена активная фаза. Витрина показывает **те же ключи**, которые
использует игра; игровой таймер клона отдельно масштабирует подготовку и возврат.

## Где менять

- `scripts/tuning.gd` — скорости, стамина, тайминги, дальность, камера.
- `tools/animation/build_motion_set.py` — авторские траектории и опорные позы.
- `scripts/character_anim.gd` — проигрывание и смешивание библиотеки.
- `scripts/player.gd`, `scripts/clone_enemy.gd` — физика и окна урона.

Скорости теперь **1.65 м/с шагом и 4.6 м/с бегом** вместо 3.4 / 6.2; дальность
кулака — **1.10 м между центрами тел** вместо 1.9–2.0 м. Это осознанная настройка
под новый шаг и видимый контакт, а не обязательный окончательный баланс.

## Проверки

С установленным Godot, из корня репозитория:

```sh
python prototype/tests/run_headless.py --godot /path/to/godot
```

Проверяются импорт, 14 нативных клипов, смена стоек при 30/60/120 FPS,
независимые R/T и меню, таймеры обеих рук и клона, прыжок/приземление в обоих
режимах, реальное столкновение со стеной, неуязвимость уклонения и витрина.
Скрипт проверяет и код возврата, и ошибки в выводе Godot.

Для офлайн-проверки геометрии и пересборки ключей — [инструкция](ANIMATIONS.md).
Необязательный браузерный просмотрщик — в [`animation_preview/`](animation_preview/README.md).

## Ограничения

Это новая рабочая база, **не финальный мокап-набор**. Пока нет оружейных
комбо, блока, отдельного набора смертей, анимаций расчленения и рига пальцев.
Кулаки постоянно сжаты в существующей модели. Уклонение — низкий рывок, не
перекат. Стопы рассчитаны для плоскости: адаптации к лестницам и склонам пока нет;
на резком развороте/смене походки возможен остаточный сдвиг стоп.

Godot 4.7.2 проверен в headless-режиме, позы и циклы — в 3D-просмотрщике.
**GPU-рендер Godot и FPS на GeForce 940MX здесь не измерялись.** Комната, свет,
материалы, отсутствие звука и общий объём игры остаются прототипными.
