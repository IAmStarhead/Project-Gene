# Прототип Gen — первая тестовая комната

**Движок:** Godot 4.7.2, рендерер **Compatibility (OpenGL 3.3)** — под GeForce 940MX.
**Что это:** комната, в которой можно ходить, бить цель и уворачиваться. Без модели
героини и без анимаций — специально, чтобы проверить **ощущение управления** раньше,
чем мы вложимся в анимации.

## Как запустить

1. Открыть Godot 4.7.2.
2. `Импорт` → выбрать файл `prototype/project.godot` в склонированном репозитории.
3. Нажать `F5`.

Первый запуск может занять несколько секунд: Godot создаст папку `.godot/` с кэшем.
Она уже добавлена в `.gitignore`, в репозиторий не попадёт.

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | идти |
| Shift | бег |
| Левая кнопка мыши | удар |
| Пробел | уворот (в направлении ввода) |
| Esc | освободить курсор |
| ЛКМ | снова захватить курсор |

## Что смотреть в первую очередь

1. **Плавность.** Нет ли рывков, не «плывёт» ли камера.
2. **Отзывчивость.** Удар и уворот должны срабатывать сразу по нажатию. Если кажется,
   что нажатие «проглатывается» — значит буфер ввода надо увеличить.
3. **Вес удара.** Удар на 0,18 с замаха + 0,12 с активных кадров + 0,26 с восстановления.
   Если бой ощущается «ватным» — уменьшаем восстановление; если слишком быстрым — увеличиваем.
4. **Уворот.** Неуязвимость с 0,04 по 0,30 с. В отладочной панели видно состояние
   `уворот [неуязвим]` — можно проверить, что окно действительно есть.
5. **FPS.** Слева сверху. На 940MX при 1280×720 мы хотим видеть уверенные 60 или
   стабильные 30. Это и есть первая проверка производительности.

## Где настраивать

**Все числа — в `scripts/tuning.gd`.** Скорость, чувствительность мыши, тайминги
удара, окно неуязвимости, буфер ввода, стамина. Правите число → `F5` → сравниваете.

## Что здесь есть и чего нет

| Есть | Нет |
| --- | --- |
| Движение с ускорением и поворотом | Модель героини (пока капсула) |
| Камера от третьего лица с антиклиппингом | Анимации |
| Уворот с неуязвимостью и стаминой | Настоящий противник (пока столб) |
| Атака: замах → удар → восстановление | Расчленение, кровь, потеря глаза |
| Отмена атаки уворотом, буфер ввода | Звук |
| Белая комната с колбами и ступенями | Текстуры (материалы простые) |
| Счётчик FPS и отладочная панель | Освещение с запеканием |

## Ограничения, о которых честно

- **Я не запускал этот проект.** Движок в моём окружении не устанавливается,
  поэтому первый запуск — проверка на Вашей стороне. Ошибка вполне возможна,
  и это нормально: пришлите текст из панели «Вывод», я исправлю.
- Сцена собирается **кодом** (`build_scene.gd`), а не в редакторе. Сделано так,
  чтобы файлы можно было проверять в тексте. Когда комната усложнится, перенесём
  в обычную сцену.
- Производительность не измерена. Комната намеренно простая: 2 источника с тенями,
  6 «световых панелей» без света, 4 цилиндра-колбы.
