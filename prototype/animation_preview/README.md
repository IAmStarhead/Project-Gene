# GEN Motion Lab — дополнительная витрина в браузере

Это **не веб-версия игры**. Просмотрщик показывает рабочий
`female_A_rigged_safe.glb` и `motion_set.json`, который генерируется одновременно
с Godot `motion_set.tres`. Никакой отдельной подборки поз в JavaScript нет.
Материал нейтральный, диагностический; игровой селлшейдинг здесь не эмулируется.

## Запуск

Нужен Node.js 18+:

```sh
cd prototype/animation_preview
npm ci
npm run dev
```

Открыть адрес, который напечатает сервер (локально порт **5173**). В Arena
использовать живое превью этого порта. Все ресурсы запрашиваются относительно
адреса страницы: браузеру пользователя не требуется доступ к sandbox localhost.
Сервер слушает `0.0.0.0`; порт можно изменить переменной `PORT`.

Для запуска **самой игры эта папка не нужна**: достаточно Godot и витрины H.
Файл `.gdignore` не позволяет Godot импортировать содержимое `node_modules`.

## Возможности

- Все 17 клипов: новые обычные стойка/ходьба/бег, четыре направления уворота и боевые движения.
- Пауза, 0.25× / 0.5× / 1×, ползунок и шаг 1/60 с.
- Орбита мышью, масштаб, ракурсы спереди/сбоку/сзади/¾.
- Лабораторное платье с лёгкой динамикой подола, настоящая мягкая форма кистей.
- Одежду можно временно скрыть для проверки полного цикла ног; это диагностическая опция.
- Скелет, индикаторы фазы опоры, траектория кулака с отметкой контакта.
- Пробел — пуск/пауза; стрелки — кадр, пока фокус не в поле ввода.
- Интерфейс на русском, включая узкий экран.

Индикатор стоп — **фаза клипа**, не результат физической трассировки поверхности.
Ходьба и бег здесь показаны на месте; в игре перемещается `CharacterBody3D`.
Воздушные клипы — отдельные **движущиеся сегменты**. В игре их прогресс связан
с вертикальной скоростью, а не с зацикливанием. Полный полёт проверяйте по F в
Godot; [текущая видеопроверка](../../reports/animation-review/natural-motion-dodges-uniform.mp4)
отрисована по экспортированным нативным позам, физической траектории и точкам ткани.
`appearance.js` — диагностическое зеркало native-одежды, не отдельный костюм.
JSON-ассет общий; свободная браузерная симуляция не обязана побитно повторять Godot.

## Автотест

С запущенным сервером и установленным Chrome/Chromium:

```sh
CHROMIUM_EXECUTABLE=/path/to/chromium npm test
```

В PowerShell переменную задают так: `$env:CHROMIUM_EXECUTABLE = 'C:\...\chrome.exe'`.
На Linux/macOS стандартные пути Chromium/Chrome определяются автоматически.
Браузер **не скачивается** при `npm ci`.

Необязательные переменные: `PREVIEW_URL`, `REVIEW_DIR` (сохранить снимки),
`SOFTWARE_GL=1` (SwiftShader для headless-среды). Скриншоты сохраняйте вне Git,
например в `.local/review/` из корня репозитория.

Тест проходит по всем 17 клипам и 85 позам, проверяет SHA рабочей модели,
направление ударов, обычные низкие руки, высоту таза и положение беговых
локтей/кистей, реальное раскрытие пальцев, геометрию платья/подола,
неподвижность ткани на паузе, детерминированный seek и возобновление симуляции,
элементы управления, мобильную ширину и изоляцию сервера.
Сервер отдаёт только файлы витрины, три явно указанных ассета и модули Three.js;
доступ к `.git` и остальной файловой системе не открывается.

Three.js — MIT; текст лицензии находится в установленном пакете. Сведения о
модели и её компонентах — в [`models/heroine`](../../models/heroine/README.md).
