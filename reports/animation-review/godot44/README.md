## Таблицы

- `shoulder-comparison.jpg`, `hem-comparison.jpg`, `hem-back-comparison.jpg`:
  **appearance-only d67fef7 + текущие позы**, не историческое прохождение.
  23 точные пары исходных снимков; 12 пар в таблицах. До/после — одинаковые
  камера/hips/rotations/покрытие. 1000×700 → 600×420, без crop/ретуши.
  Полная кожа помечена и существует только в изолированной диагностике.
- `wardrobe-comparison.jpg`: четыре пары из 61 точной пары текущих игровых
  поз, та же сцена/свет/observer. Проверены оба актёра. 800×450 → 480×270.
- `contacts-1.jpg` … `contacts-4.jpg`: восемь названных actual-controller
  snapshots с двух сторон/сзади. **Повторный рендер замороженной позы, не новое
  контроллерное покрытие**. Малиновая — production-кожа; красная контактная
  ткань приподнята на **0.5 мм** ради overlay, не измеренная глубина пробоя.
  1000×700 → 500×350. Все исходные пиксели только равномерно уменьшены.

Соответствующие `comparisons.json`, `wardrobe-comparison.json`, `contacts.json`
сохраняют source/manifest/image hashes и условия. Контакты не объявлены скрытыми
или исправленными только по принадлежности к facing/binding; заломы остаются.

не замена исходным тестам и не универсальная гарантия. Сырые PNG/трассы, движок,
браузер, PCK и эксперименты хранятся игнорируемыми: `.local/review/repair-44/`.

контакты — `contacts-fillet`. Этой `.local` папки может не быть в новом клоне.
