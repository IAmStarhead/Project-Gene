# Просмотр движений

## Актуальная ходьба и бег — `gait-upright.mp4`

Сравнение походки **до / после** исправления постоянного приседа по видео
пользователя. Слева — ключи из коммита `191be87`, справа — исправленные.
Одна модель, одинаковые камера, масштаб, материал и уровень пола.

- 1024×640, 24 кадра/с, 12 с, без звука.
- Оба цикла воспроизводятся на 1× по своему времени: длительность ходьбы стала
  0.76 с вместо 0.82 с, поскольку шаг чуть короче. Фазы намеренно не синхронизированы.
- Скорости перемещения в игре и боевые действия этой правкой не менялись.
- Сначала вид сбоку, затем ¾.
- Это **диагностический рендер запечённых ключей Three.js, не запись игры Godot**.

[Что исправлено и как проверено](../27-осанка-ходьбы-и-бега.md).

## Первоначальный набор — `motion-review.mp4`

Историческая запись первой итерации библиотеки (отчёт 26). Ходьба и бег в ней
ещё **до исправления осанки**; остальные девять клипов остались прежними.
Рендер существующего skinned GLB по ключам `motion_set.json`, который генерируется
вместе с нативной библиотекой Godot. Независимых поз для видео нет.

- 800×720, 24 кадра/с, около 27 с, без звука.
- Некоторые действия показаны на 0.65× и подписаны.
- Модель отображена нейтральным материалом в Three.js.
- Это **не захват игрового окна Godot и не замер FPS**.
- Высоту полного прыжка определяет игровая физика; здесь показаны его отдельные состояния.

Сырые кадры, браузер, зависимости и копии видео пользователя в Git не включены.
[Первоначальный отчёт о проверках и ограничениях](../26-единая-библиотека-анимаций.md).
