# 19. Настоящая причина «тянется кожа», свет, прыжок и клон

Дата: 17 ноября 2026. Четыре правки по замечаниям пользователя: кожа,
освещение, прыжок, противник с переключаемым режимом боя.

## 1. Кожа: причина была не в ударе, а в весах скелета

Прошлый отчёт (18) лечил позу удара. Пользователь справедливо ответил:
«изменений не вижу, кожа всё равно натягивается». Прав.

Просмотрщик поз позволил найти настоящую причину. Я взял позу удара и
посмотрел, **какие именно рёбра** тянутся больше чем вдвое — их оказалось
34. Дальше по этим рёбрам нашлись вершины и их веса:

```
v4786: (-0.114, 0.817, -0.061)   hips=0.43  thigh.R=0.43  hand.R=0.13
v4930: (-0.178, 0.791, +0.013)   thigh.R=0.53  hand.R=0.37
v7032: (-0.173, 0.728, +0.039)   thigh.R=0.70  hand.R=0.30
```

Вершины **на бедре** имеют вес **кисти**. Скелет собирался автоматически:
веса считались по расстоянию от вершины до кости. Кисть в позе покоя висит
ровно у бедра, поэтому её влияние «прожгло» бедро насквозь.

Когда рука идёт вперёд на удар, кожа бедра тянется за кистью. Это и есть
«кусок кожи поднимается» — только не на груди, а на бедре, и видно его
сбоку.

Масштаб, посчитанный по всей модели:

| Часть тела | Ошибочный вес | Вершин |
| --- | --- | --- |
| бедро R | `hand.R` | 154 |
| бедро L | `hand.L` | 154 |
| таз | `forearm.L` | 119 |
| таз | `forearm.R` | 115 |
| таз | `hand.R` | 66 |
| таз | `hand.L` | 66 |
| бедро R | `forearm.R` | 56 |
| бедро L | `forearm.L` | 56 |

Всего **561 вершина**.

### Что сделано

В `sanitize_glb.py` добавлена функция `fix_burnthrough_weights`. Она
переносит ошибочный вес на главную кость вершины. Правило адресное,
по **имени кости**: «на вершинах, где главная кость — бедро, не может быть
веса кисти».

Именно поэтому прошлая попытка провалилась: там правило было по координатам
(`|X| < 0.17`), и оно резало живую руку — границы между рукой и торсом
у модели нет.

Геометрия, скелет и остальные веса не тронуты.

## 2. Свет

Пользователь: «моделька выглядит ужасно из-за нынешнего освещения».
Причина не в яркости, а в том, что её было слишком много **сразу**.

| Параметр | Было | Стало |
| --- | --- | --- |
| ambient_light_energy | 1.15 | **0.45** |
| sun.light_energy | 1.5 | **1.0** |
| заполняющие источники | 2 (0.85 и 0.6) | **1 (0.35)** |
| tonemap | FILMIC | **LINEAR** |
| фон | 0.82, 0.86, 0.92 | 0.62, 0.66, 0.72 |
| анизотропия текстур | 0 (выкл) | 2x |
| MSAA | 0 (выкл) | 2x |
| FXAA | — | вкл |

Ключевое: **текстура кожи сама по себе яркая** — средняя яркость 0.77.
При освещённости 1.15 + 1.5 + 1.45 она гарантированно уходила в белое,
и на теле не оставалось ни одного теневого перехода. Теперь суммарно
примерно втрое темнее, и объём читается.

Заодно FILMIC убран: он дополнительно сжимал яркость поверх уже
пересвеченной сцены.

## 3. Прыжок

Клавиши как в Elden Ring по умолчанию: **F — прыжок, Space — уворот**
(проверено по документации управления ER на PC).

| Параметр | Значение |
| --- | --- |
| высота прыжка | 1.15 м |
| начальная скорость | `sqrt(2 * 24 * 1.15)` ≈ 7.4 м/с |
| гравитация при подъёме | 24 |
| гравитация при падении | **34** — падать быстрее, чем взлетать |
| управление в воздухе | 55 % |
| буфер ввода | 0.16 с |
| coyote-time | 0.10 с (прыжок сразу после схода с края) |

Плюс отдельная поза в полёте: ноги подобраны, руки разведены. Без неё
процедурный шаг продолжал «перебирать ногами» в воздухе.

## 4. Клон с переключаемым режимом боя

Противник собран из **той же модели**, что героиня (замысел «клон»),
с той же процедурной анимацией.

Режимы переключаются клавишей **T**:

| Режим | Поведение |
| --- | --- |
| **спит** | стоит, не реагирует, ранить нельзя |
| **следит** | идёт за героиней, не бьёт |
| **бьёт** | сближается, держит дистанцию, атакует, отходит после удара |

Стартует в режиме «спит» — чтобы не убивать тестировщика в момент, когда тот
смотрит на свет или текстуру.

Боевое поведение:

| Параметр | Значение |
| --- | --- |
| здоровье | 120 |
| дистанция удержания | 1.6 м |
| радиус удара | 2.0 м |
| урон | 14 |
| замах | 0.34 с (вдвое длиннее, чем у игрока — чтобы успевать реагировать) |
| активная фаза | 0.12 с |
| восстановление | 0.45 с (окно для контратаки) |
| пауза между ударами | 0.9 с |

Подпись над героиней показывает текущий режим и здоровье клона.

Столб-заглушка оставлен рядом: на нём удобно проверять конус удара,
не трогая клона.

## Что смотреть

1. **Кожа на бедре при ударе** — должно перестать тянуться.
2. **Освещение** — лицо и тело должны читаться объёмом, без белого пятна.
3. **F** — прыжок. Проверьте, что не проваливается сквозь пол.
4. **T** — клон: три нажатия = три режима. В «бьёт» подойдите и дайте
   себя ударить, проверьте, что удар заметен по замаху.
