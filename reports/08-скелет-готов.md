# Отчёт 08 — проверка модели и первый скелет

**Дата:** 17 ноября 2026
**Статус:** скелет собран и проверен программно. Исходные файлы не изменены.
**Артефакт:** `models/heroine/female_A_rigged.glb` (4,53 МБ), вид деформации — [`analysis/rig-pose-test.png`](analysis/rig-pose-test.png)

## 1. Проверка модели: подходит ли она под скелет

Разобрал GLB по данным, а не по описанию.

| Параметр | Значение |
| --- | --- |
| Рост | **1,675 м** |
| Вершин / треугольников тела | 18 176 / 33 300 |
| Габариты | X 0,472 м, Y 1,675 м, Z 0,267 м |
| Нормали, UV, материалы | на месте; обе текстуры **без нормалей** (roughness 0,88) |
| Скелет | **отсутствует** |
| Морфы | 4 на кисти, 1 на моргание, 2 на линию века |
| Открытые края | 114 — узкое кольцо на шее, «дно» глаза |
| Неманифолд | 0 (проверено по рёбрам) |
| Мелкие отдельные островки | 364 одиночных вершины (шум базовой модели) |

**Вывод: модель подходит для скелета.** Она в позе «стоя, руки вниз», с анатомически верными пропорциями, без зеркальных дублей и без перевёрнутых нормалей.

**Что учесть на будущее (для расчленения):**
- Тело — **единая поверхность**: нет швов на локтях, коленях и запястьях. Деления на конечности не существует ни в геометрии, ни в топологии. Для отсечения придётся отсекать по плоскости шейдером либо делить меш на куски с «заглушками» ран.
- Торс и верхняя часть бёдер **сварены в один кусок** (5519 вершин), руки не отдельные объекты.
- Стопы от 0,00 до 0,10 м — модель стоит на земле ровно (Y = 0).
- Лицо смотрит в **+Z**.

## 2. Что я сделал

Blender в моём окружении запустить нельзя (нет X-библиотек, установить их через apt не даёт прав). Поэтому скелет собран **программно, без Blender** — скриптом, который читает GLB и дописывает в него кости и веса, не перекодируя исходную геометрию.

- **Скрипт:** [`../models/heroine/rig/tools/build_rig.py`](../models/heroine/rig/tools/build_rig.py)
- **Проверка рендером:** [`../models/heroine/rig/tools/render_rig_test.py`](../models/heroine/rig/tools/render_rig_test.py) — собственный программный рендер со скиннингом, чтобы увидеть деформацию без движка.
- **Результат:** `models/heroine/female_A_rigged.glb`
- **Отчёт по костям:** `models/heroine/female_A_rigged.info.json`

Исходные `female_A_ears_refined.glb` и `female_A_eyes_refined.glb` **не изменены** — SHA-256 совпадают с указанными в README модели.

### Скелет: 21 кость

`hips → spine → chest → neck → head`, руки `shoulder/upper_arm/forearm/hand` с каждой стороны, ноги `thigh/shin/foot/toe` с каждой стороны. Четыре влияния на вершину — столько же поддерживает Godot и большинство движков.

### Проверки, которые пройдены

| Проверка | Результат |
| --- | --- |
| glTF Validator (Khronos), ошибки | **0** |
| Поза покоя не искажает модель | отклонение от единичной матрицы **5·10⁻⁸** |
| Морфы сохранены | 4 / 0 / 2 / 1 на четырёх мешах |
| Клипы сохранены | `Blink_Once`, `Fists_Close`, `Fists_Open` |
| Торс при поднятой руке | макс. 13 см только у подмышечной складки, среднее 0,07 см |

## 3. Что видно на проверке поз

[`analysis/rig-pose-test.png`](analysis/rig-pose-test.png) — шесть поз: покой, рука вверх с согнутым локтем, удар правой, приседание, поворот головы, наклон корпуса.

- **Работает:** локти, колени, шея, наклон корпуса — гнутся правильно, конечности не «резиновые».
- **Ограничение:** при сильном подъёме руки вверх (на 95°) у подмышки натягивается перемычка — на модели **нет подмышечной впадины как отдельной геометрии**, тело сварено. Это убирается сглаживанием весов и ограничением угла подъёма, но для «руки строго вверх» понадобится правка геометрии.

## 4. Где я мог ошибиться

- Рендер проверочный, **не показывают реальную картинку в Godot**: цвет, текстуры и материалы там будут другими.
- В Godot я модель **не импортировал** — движок в песочницу не устанавливается. Импорт проверите Вы.
- Кости расставлены **по расчёту из геометрии**, а не художником. Для анимаций этого достаточно, но для тонкой мимики и пальцев — нет: **пальцев в скелете нет**, кисть — одна кость.

## 5. Противник «клон» — поддерживаю

Первый враг — та же модель, это правильный выбор: одна геометрия, один скелет, одни анимации, и сразу видно, честно ли работают хитбоксы. В Godot это делается как второй экземпляр сцены с другим скриптом ИИ — дублировать файлы не нужно.

## 6. Что дальше

1. Вы импортируете `female_A_rigged.glb` в Godot и присылаете скриншот/ошибку.
2. Я делаю набор базовых анимаций (стойка, ходьба, бег, удар, уворот) — **программно, ключевыми кадрами**, тем же способом, без Blender.
3. Затем белая комната, управление и первый бой с клоном.
