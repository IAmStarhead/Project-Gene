# Исходная сетка героини

`female_A_original.glb` — модель **до всех доработок** (брови, уши, глаза, кисти,
ресницы). Основа — сетка MakeHuman/MPFB2 (CC0).

- SHA-256: `23428079f47cf54b2a5dc9b4dc7799dbc7afb27a06f8f1a67a69972dc593f7ec`
- Источник: `IAmStarhead/Blades-Of-War`, коммит `b093a00`, путь `assets/models/female_fixed.glb`
- Хеш совпадает с `SOURCE_MODEL_SHA` в `build.py` предшественника — значит файл подлинный.

Нужна, если придётся переделывать геометрию с нуля: форму тела, пальцы, деление
на конечности для расчленения. Рабочие версии лежат уровнем выше.
