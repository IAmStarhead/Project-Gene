# Скелет героини — рабочая копия

Здесь лежат файлы скелета. **Исходные модели не изменяются**: скелет собран как
отдельный файл рядом с ними.

- `../female_A_rigged.glb` — модель со скелетом (21 кость, до 4 влияний на вершину).
  Исходник `../female_A_ears_refined.glb` остаётся нетронутым.
- `../female_A_rigged.info.json` — координаты костей и распределение весов.
- `tools/build_rig.py` — сборка скелета без Blender: читает GLB, дописывает кости
  и веса, не перекодируя исходную геометрию.
- `tools/render_rig_test.py` — программный рендер со скиннингом: проверка деформации
  в тестовых позах без движка. Результат — `reports/analysis/rig-pose-test.png`.

## Пересборка

```bash
python3 models/heroine/rig/tools/build_rig.py       # собрать скелет
python3 models/heroine/rig/tools/render_rig_test.py # проверить деформацию
```

Требуется только `numpy`; для проверки ещё `Pillow`.

## Ограничения

- Пальцев в скелете нет: кисть — одна кость. Мимики нет.
- Геометрия тела сварена: подмышечной впадины и швов на локтях/коленях нет,
  поэтому при подъёме руки выше ~90° у подмышки появляется натяжение.
- Для отсечения конечностей понадобится отделить куски меша или отсекать
  геометрию шейдером — в текущем виде тело единое.
