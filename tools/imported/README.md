# Инструменты, перенесённые из прежнего репозитория

Скопировано из `IAmStarhead/Blades-Of-War`, коммит `7fa31c89134f0b54d83a25a3ed8b4321a97113cf`,
каталог `tools/`. **Ничего не изменялось** — это архив предшественника, чтобы геометрия
героини оставалась воспроизводимой.

| Каталог | Что делает |
| --- | --- |
| `model-a-refinement` | основная сборка модели: дельты целей MakeHuman, нормали в области правки, брови в текстуре, ресницы |
| `model-a-motion` | **моргание и кулаки**: морфы и клипы `Blink_Once`, `Fists_Close`, `Fists_Open` |
| `model-a-hand-ear` | кисти и уши |
| `model-a-ear-study` | проба формы ушей (последняя правка перед переносом) |
| `model-a-eye-study` | глаза |
| `model-a-brow-study` | брови |
| `model-a-relief` | рельеф кожи и освещение |
| `model-a-revision` | правки внешности |
| `model-a-lashes` | ресницы |
| `model-a-fist-trial` | первые пробы кистей |
| `character-showcase` | витрина и прототип показа |

## Исходная сетка

`models/heroine/source/female_A_original.glb` — сетка до всех доработок.
SHA-256 `23428079f47cf54b2a5dc9b4dc7799dbc7afb27a06f8f1a67a69972dc593f7ec` совпадает
с тем, что указывает `build.py` предшественника (`SOURCE_MODEL_SHA`), то есть это
подлинный исходник, а не приблизительная копия.

## Зависимости

`requirements.txt` в каждом каталоге: `numpy`, `Pillow`. Для проверок витрины нужен Node.js
(`qa-browser.mjs`, `qa-gltf.mjs`).

## Чего здесь нет

- Архивов витрин (`*.zip`) — они тяжёлые и не нужны для сборки.
- Готовых GLB промежуточных версий — они уже есть в `models/heroine/`.
- Отдельного инструмента для сборки витрины `tools/character-showcase` включён, но
  он рассчитан на структуру прежнего репозитория; для запуска может понадобиться
  поправить пути.

## Что это даёт

Геометрию теперь можно **пересобрать с нуля**: изменить форму тела, добавить пальцы,
разделить тело на конечности для расчленения. Раньше у нас был только результат (GLB).
